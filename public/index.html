Image Translation Layer

Proxy any comic site — translate text & images on the fly

How it works

  1. Paste any comic website URL above
  2. Pick the source & target language
  3. The proxy fetches the page, translates HTML text, and rewrites links
  4. Images with text (speech bubbles, SFX) are detected via OCR and overlaid with translations
  5. Click any image on the proxied page to trigger image translation
